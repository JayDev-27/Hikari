## Key design rules

- **One clock.** Audio chunks are scheduled on the WebAudio clock; lip-sync phonemes and gesture `atMs` are stored as AudioContext times; the frame loop samples at `audibleTime()` (output-timestamp compensated). Target A/V error ≤ ±40 ms.
- **Renderer-agnostic avatar.** Everything above `AvatarController` (lip sync, gestures, emotions, states) is shared by Live2D and VRM.
- **The frame loop is owned by `StageRuntime`** (Pixi `autoStart: false`), so render FPS can be throttled when idle (30 fps idle / 60 fps animating, §9) without touching renderers.
- **Click-through:** the window starts ignoring cursor events; Rust polls the global cursor; the stage hit-tests with a 1-px alpha `readPixels` right after rendering (plus Live2D hit areas for "head"/"body"); toggles only on change, 60 ms hysteresis back to click-through.
- **Protocol first.** `packages/protocol/schema/protocol.schema.json` is the single source; TS generated by `gen-ts.mjs` (zero deps), Pydantic by B. Versioned (`v`, `hello` handshake rejects major mismatch).
- **Barge-in:** UI stops audio within one render quantum (5 ms fade), clears lip sync + pending gestures, and reports `playedUntilSeq/playedMsInSeq` so core trims history to what was actually heard.
- **Assets never committed:** Cubism Core and models are fetched by `apps/desktop/scripts/fetch-assets.mjs`; packs (`characters/<id>/character.json`) are committed.
