# Security

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/JayDev-27/Hikari/security/advisories/new), not in a public issue.
Include what you found, how to reproduce it and what it could affect. You'll get a reply within a week.

Hikari runs locally and asks before every action on your Mac, so reports about the confirm dialog, the audit log,
Keychain handling, the local WebSocket (`127.0.0.1:8765`) or model/pack loading are especially welcome.
